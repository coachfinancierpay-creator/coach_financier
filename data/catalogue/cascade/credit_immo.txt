cascade - DECISION TREE — MORTGAGE
=====================================

Role: check the feasibility of a property project and recommend the most suitable financing package.
Usage: follow the steps in order; apply the first condition that matches the customer.


STEP 1 — Scope
- IF the project is NOT genuinely a property project: THEN leave the mortgage flow.
- OTHERWISE: go to step 2.


STEP 2 — Financial feasibility
Check: available down payment; stable income; existing loans; debt-to-income ratio; remaining income after charges; savings left after purchase; notary fees / guarantee / works.
- IF the project is NOT sustainable: THEN do not propose financing.
- IF the project is sustainable: go to step 3.


STEP 3 — Buying before selling the current home?
- IF the customer buys before having sold the current home:
  THEN propose a « Bridging Loan » (+ additional mortgage if needed).
- IF NO: go to step 4.


STEP 4 — Primary residence?
- IF the project is a primary residence:
    1. If first-time buyer:
       - PTZ eligible → include the « PTZ » as a priority;
       - otherwise → continue.
    2. If income compatible with the « PAS » → compare PAS + PTZ + standard loan.
    3. Otherwise, if « Subsidised Loan » relevant → compare.
    4. Otherwise → « Fixed-Rate Mortgage ».
- IF NO (not a primary residence): go to step 5.


STEP 5 — Rental investment?
- IF YES:
    - Wealth profile / relevant « in fine » strategy → compare « In Fine Mortgage » vs « Fixed-Rate Mortgage ».
    - Otherwise → « Fixed-Rate Mortgage ».
- IF NO: go to step 6.


STEP 6 — PEL / CEL with borrowing rights?
- IF the customer has a PEL or CEL with borrowing rights: calculate the value of the « Home Savings Loan » and compare it with the rate of the main loan.
- IF NO: go to step 7.


STEP 7 — Energy renovation works?
- IF YES: check the « Zero-Interest Eco Loan » (+ main loan if needed).
- IF NO: go to step 8.


STEP 8 — BFM / public sector eligible?
- IF YES: apply the BFM advantages / an adapted guarantee.
- IF NO: go to step 9.


STEP 9 — Complete the financing plan
- Complete with the « SG Fixed-Rate Mortgage ».


STEP 10 — Ancillary costs to include
- mortgage protection insurance; guarantee / surety; arrangement fees; notary fees; works; charges / property tax.


STEP 11 — Answer to the customer (LLM)
Explain in English the recommended financing package and the alternatives.
